# Video Game Rating Software
This software is designed for users to rate individual games based on their personal preferences!

## Features (WIP)
-User login and individual accounts
-Adding games to a user's library
-Rating individual games based on different criteria
-Adding notes to ratings to explain your reasoning for future retrospective
-Searching for a game in your list

## Tech Stack
-Frontend: HTML + CSS with Flask
-Backend: Python
-Database: SQLite with SQLAlchemy
